# spike-service-worker

A minimal TypeScript PWA spike for validating offline behavior, GitHub Pages hosting, and installability on iOS Safari.

## Local development

```bash
npm install
npm run build
```

Serve `/home/runner/work/spike-service-worker/spike-service-worker/docs` with any static server to test the built site locally.

## GitHub Pages

This repository builds into `docs/`, so GitHub Pages can publish the site directly from the repository by using the `docs` folder.
